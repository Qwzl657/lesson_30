# lesson_30


Описание реализованных методов

calculateTotal()
Вычисляет общую стоимость заказа как сумму произведений цены товара на его количество.  
Если заказ оформлен с доставкой на дом, к общей сумме добавляется 10%.

printOrders()
Выводит в консоль список всех заказов с информацией о клиенте, сумме заказа и типе доставки.

topMostExpensive(int n)
Возвращает список из n заказов с наибольшей общей стоимостью.

topCheapest(int n)
Возвращает список из n заказов с наименьшей общей стоимостью.

homeDeliveryOrders()
Возвращает список всех заказов, оформленных с доставкой на дом.

bestAndWorstHomeDelivery()
Определяет самый дорогой и самый дешёвый заказ с доставкой на дом без использования сортировки.

ordersBetween(double min, double max)
Возвращает список заказов, сумма которых находится в диапазоне от min до max.

totalIncome()
Считает общую сумму всех заказов ресторана.

uniqueSortedEmails()
Возвращает отсортированный набор уникальных email-адресов клиентов без использования методов сортировки.

ordersByCustomerName()
Группирует заказы по имени клиента.

totalByCustomer()
Вычисляет общую сумму заказов для каждого клиента.

richestCustomer()
Определяет клиента с максимальной суммой всех его заказов.

poorestCustomer()
Определяет клиента с минимальной суммой всех его заказов.

### soldItemsCount()
Подсчитывает общее количество проданных товаров, сгруппированных по названию товара.
